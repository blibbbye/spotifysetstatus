First-time setup

Run Spotify Status Connector.exe on Windows. Keep it open while using this page.
Open Discord Desktop and create an application in the Developer Portal.
Copy its Application ID. In the connector, choose Settings, paste the ID, and press Save & reconnect.
Return here, enter the track details, and press Set status.
Custom Discord activity bridge. It does not connect to your Spotify account or play audio.
For the closest icon match, use the included green music mark as your Discord application's icon.
